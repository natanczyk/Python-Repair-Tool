Write the function lab9ex8b that receives two sparse matrices represented as dictionaries and returns their sum as a new sparse matrix dictionary.

A sparse matrix is represented as a dictionary where keys are (row, col) tuples and values are the non-zero element values at those positions.

The sum is computed as: for each position that appears in either matrix, the result value is the sum of the values at that position (treating missing positions as zero).

For example:

e1 = {(1, 5): 4, (2, 3): 9, (4, 1): 1}
e2 = {(1, 6): 2, (4, 1): 2, (5, 4): 2}
lab9ex8b(e1, e2)
{(1, 5): 4, (2, 3): 9, (4, 1): 3, (1, 6): 2, (5, 4): 2}
