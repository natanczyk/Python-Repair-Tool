Write the function lab8ex3 that receives a list of numbers and returns a list containing the cumulative sum of the received list.

The element at position i of the returned list contains the sum of all elements from positions 0 to i in the original list.

Input validation is not required.

For example:

lab8ex3([1, 2, 3, 4, 5])
[1, 3, 6, 10, 15]
