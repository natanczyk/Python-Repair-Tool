Using only recursion (no loops), define the function lab13ex2 that receives two sorted lists (in non-decreasing order) and returns a single sorted list containing all elements from both lists.

The function must preserve duplicate values and maintain non-decreasing order in the result.

For example:

lab13ex2([], [])
[]

lab13ex2([1, 3, 5], [2, 4, 6])
[1, 2, 3, 4, 5, 6]

lab13ex2([2, 5, 90], [3, 5, 6, 12])
[2, 3, 5, 5, 6, 12, 90]

lab13ex2([1, 2, 3], [1, 2, 3])
[1, 1, 2, 2, 3, 3]

lab13ex2([-3, -1, 0, 2], [-2, 1, 3])
[-3, -2, -1, 0, 1, 2, 3]
