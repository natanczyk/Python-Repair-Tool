Write the function lab10ex7 that receives a string corresponding to a file name and prints the lines of the file sorted in increasing lexicographic order.

For example, if file fich contains:

Another file to perform the same tests.
This file contains one more line
besides this one.

then:

lab10ex7('fich')

produces:

'This file contains one more line'
'Another file to perform the same tests.'
'besides this one.'
