Using only pure functions and the higher-order functions map, reduce, filter, any, all, and fixedPoint, define the higher-order function lab11ex12a that receives a function f, an element x, and a non-negative integer n, and returns f applied n times to x:

f^n(x) = f(f(...f(x)...))    (f applied n times)

If n = 0, return x unchanged.

For example:

lab11ex12a(lambda x: x + 1, 0, 5)
5

lab11ex12a(lambda x: x * 2, 1, 3)
8

lab11ex12a(lambda x: x ** 2, 2, 3)
256
