This exercise requires explaining what the following uses of the higher-order function somatorio do:

def somatorio(l_inf, l_sup, calc_termo, prox):
    soma = 0
    while l_inf <= l_sup:
        soma = soma + calc_termo(l_inf)
        l_inf = prox(l_inf)
    return soma

(a) somatorio(4, 500, lambda x: x, lambda x: x + 1)
    Computes the sum of integers from 4 to 500 inclusive.

(b) somatorio(5, 500, lambda x: x * x, lambda x: x + 5)
    Computes the sum of squares of multiples of 5 from 5 to 500.

(c) somatorio(1, 5, lambda x: somatorio(1, x, lambda x: x, lambda x: x + 1), lambda x: x + 1)
    Computes the sum of triangular numbers T(1)+T(2)+T(3)+T(4)+T(5)
    where T(n) = 1+2+...+n (the n-th triangular number).
    Result: 1 + 3 + 6 + 10 + 15 = 35

This is an explanation exercise — no function to implement.
