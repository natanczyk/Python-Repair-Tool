Using only recursion (no loops), define the function lab13ex12 that receives two lists — a candidate suffix and a reference list — and returns True if the first list is a suffix of the second list, or False otherwise.

An empty list is always a suffix of any list. A list is a suffix of itself. A list longer than the reference list is never a suffix.

For example:

lab13ex12([], [])
True

lab13ex12([], [1, 2, 3])
True

lab13ex12([4, 5, 6], [1, 2, 3, 4, 5, 6])
True

lab13ex12([1, 2], [1, 2, 3])
False

lab13ex12([1, 2, 3], [1, 2, 3])
True

lab13ex12([3], [1, 2, 3])
True

lab13ex12([2, 3], [1, 2, 3])
True

lab13ex12([1, 3], [1, 2, 3])
False
