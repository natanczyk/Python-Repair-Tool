Write the function lab9ex8c that receives two sparse matrices represented as dictionaries and returns their matrix product as a new sparse matrix dictionary.

A sparse matrix is represented as a dictionary where keys are (row, col) tuples and values are the non-zero element values at those positions.

The product C = A * B is computed as:
  C[i, j] = sum over k of (A[i, k] * B[k, j])

Only include positions with non-zero results in the output dictionary.

For example:

e1 = {(0,0):2, (0,3):1, (1,0):-1, (1,2):1, (2,1):3}
e2 = {(0,0):4, (1,1):1}
lab9ex8c(e1, e2)
{(0, 0): 8, (1, 0): -4, (2, 1): 3}
