Using only recursion (no loops), define the function lab13ex14 that receives a list of integers and returns the number of positive elements minus the number of negative elements.

The value 0 is considered neutral and is counted in neither group.

For example:

lab13ex14([])
0

lab13ex14([1, -2, -1, 3, 1, 2])
2

lab13ex14([1, 2, 3])
3

lab13ex14([-1, -2, -3])
-3

lab13ex14([0, 0, 0])
0

lab13ex14([1, 0, -1])
0
