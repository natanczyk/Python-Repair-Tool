Using the fixedPoint combinator and defining an appropriate pure function (without loops, variable manipulation, or explicit recursion), write the function lab11ex11c that returns the first (leftmost) digit of a natural number n.

def fixedPoint(f, x):
    while x != f(x):
        x = f(x)
    return x
