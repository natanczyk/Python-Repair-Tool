Using only recursion (no loops), define the function lab13ex15 that receives a list of lists (sublists) and returns True if at least one sublist contains strictly more even numbers than odd numbers, or False otherwise.

For each sublist, count the even and odd elements. If the count of evens is strictly greater than the count of odds in any sublist, return True. If no such sublist exists, return False. An empty outer list returns False.

For example:

lab13ex15([])
False

lab13ex15([[2, 4, 3, 1], [3, 5, 7], [8, 1, 6]])
True

lab13ex15([[1, 3, 5], [7, 9, 11]])
False

lab13ex15([[2, 4, 6]])
True

lab13ex15([[1, 2, 3], [4, 5, 6]])
True

lab13ex15([[1, 1, 2]])
False
