Define the function lab6ex13 that receives two tuples w1 and w2 and returns True if w1 is a permutation of w2 and False otherwise.

For example:

lab6ex13((1, 2, 3), (1, 2, 3))
True

lab6ex13((1, 2, 3), (2, 3, 1))
True

lab6ex13((1, 1, 1, 2, 3), (1, 2, 3))
False

lab6ex13((1, 2, 3), (1, 2, 3, 4))
False
