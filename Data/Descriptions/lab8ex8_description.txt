The Racaman sequence is a sequence of non-negative integers defined as follows:

(1) the first term is zero.
(2) to compute the n-th term:
    - if the previous term is greater than n,
      AND subtracting n from the previous term produces a value not yet in the sequence,
      then the n-th term = previous term - n (subtraction);
    - otherwise the n-th term = previous term + n (addition).

Write the function lab8ex8 that receives a positive integer n and returns a list containing the first n elements of the Racaman sequence.

For example:

lab8ex8(15)
[0, 1, 3, 6, 2, 7, 13, 20, 12, 21, 11, 22, 10, 23, 9]
